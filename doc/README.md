# beedance documentation

beedance parses and runs the IEC 61131-3 PLC languages (Structured Text,
Instruction List and Sequential Function Chart) in Go. One parser feeds
three backends: a tree-walking evaluator, a bytecode compiler with its
virtual machine, and a transpiler that generates Go for the royaljelly
runtime.

The [README](../README.md) is the quick tour. These pages are the reference.

## Module

`github.com/apiarytech/beedance`, Go 1.27.1 or later. Its only dependency
is go-cmp, in tests. Code generated by the transpiler depends on
[royaljelly](https://github.com/apiarytech/royaljelly) and, for OSCAT
functions, [beebread](https://github.com/apiarytech/beebread).
