# beedance icons

| File | Use |
|---|---|
| `beedance.svg` | Main logo, for light backgrounds |
| `beedance-dark.svg` | Same logo for dark backgrounds |
| `beedance-small.svg` | Simplified logo for 32 px and smaller (favicons, badges) |
| `png/` | PNG exports at fixed sizes, transparent background |
| `avatar-*.png` | 500 x 500 on white, for GitHub avatars and social previews |

In a README:

```html
<img src="doc/icon/beedance.svg" alt="beedance" width="96">
```
